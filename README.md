OsonPay 💳

OsonPay — zamonaviy raqamli to‘lov va moliyaviy xizmatlar ilovasi. Ilova Flutter yordamida ishlab chiqilgan va Android platformasi uchun mo‘ljallangan.

🚀 Asosiy imkoniyatlar

- 🏠 Bosh sahifa
- 💳 Bank kartalarini boshqarish
- 💸 Pul o‘tkazmalari
- 📊 Tranzaksiyalar tarixi
- 🧾 Xizmatlar uchun to‘lov
- ✈️ Aviachipta bo‘limi
- 👛 Elektron hamyon
- 👤 Profil
- 🔐 PIN va biometrik himoya
- 🔔 Bildirishnomalar

🛠 Texnologiyalar

- Flutter
- Dart
- Android
- REST API
- Backend
- Database

📱 Loyihani ishga tushirish

Flutter SDK o‘rnatilgandan so‘ng:

flutter pub get
flutter run

📦 APK yaratish

Release APK yaratish:

flutter build apk --release

Tayyor APK quyidagi manzilda bo‘ladi:

build/app/outputs/flutter-apk/app-release.apk

⚠️ Muhim

Ushbu versiya MVP/demo hisoblanadi. Hozircha real bank operatsiyalari va real pul o‘tkazmalari amalga oshirilmaydi.

Real to‘lovlarni qo‘shish uchun keyinchalik tegishli to‘lov provayderlari, backend, autentifikatsiya va xavfsizlik tizimlari integratsiya qilinadi.
